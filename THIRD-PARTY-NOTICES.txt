Quota Usage Monitor
THIRD-PARTY NOTICES

Quota Usage is a lightweight, portable, easy-to-use, customizable, open-source
usage monitor for Claude, Codex, and many other providers. It reads existing
sign-in credentials and sends usage requests directly to provider services. No
separate API key is needed when existing provider sign-ins supply credentials.
