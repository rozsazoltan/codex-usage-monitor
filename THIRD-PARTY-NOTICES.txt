Codex Usage
THIRD-PARTY NOTICES

Codex Usage is a lightweight, portable Windows quota-usage monitor. It reads
existing sign-in credentials for locally installed Codex and Claude Code tools
and sends usage requests directly to provider services. No separate API key is
needed; existing CLI sign-ins provide the credentials.
